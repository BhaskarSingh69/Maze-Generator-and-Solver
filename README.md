# Description 
Maze Generator and Solver (C++)
This is a console program that builds a random maze and then solves it. The maze is created using Depth-First Search with backtracking, which makes sure every part of it can be reached. The program then finds a route from the start to the exit using two algorithms, Breadth-First Search (BFS) and Depth-First Search (DFS). You can watch the search happen as a step-by-step animation, add extra loops to the maze, and compare how many cells each algorithm explores and how long a route it finds. BFS always finds the shortest route, while DFS may take a longer one. The project is written in plain C++ and is meant to show how data structures like stacks and queues change the way a search algorithm behaves.
